# _assets — drop zone

Put the **raw files** here: PDFs, images, screenshots, deck exports, spreadsheets — whatever you're uploading. Then write an intake note for it in the matching category folder (copy [[../_Intake-Template]]) and add it to [[../Index]].

Tips:
- Keep filenames clear (`mccqe-part1-objectives-2026.pdf`, not `scan001.pdf`).
- Reference a file from its intake note via the `asset:` field.
- Large binaries live in git here — fine for a working library. If it ever gets heavy, we can revisit storage (see [[../../Architecture]] watch-items).
- ⚠️ Don't drop anything here that would be illegal to redistribute and then bundle it publicly — see [[../../Licensing-and-Copyright]]. Storing a personal copy for reference is fine; shipping it is the line.
