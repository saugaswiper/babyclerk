# 🎯 Mission — read this first

> The one-screen anchor. Re-read at the start of every session so the work stays centered. Fuller detail in [[Vision]]; this is the compass.

## The mission
**Make clerkship a breeze for any medical student** — by pairing world-class spaced-repetition study tools with an AI that learns each student's weak spots and prepares them for exactly what's coming, by rotation and by date.

## The one bet that matters most
An **adaptive AI tutor that learns from performance** → weak-area targeting + tailored questions + date-aware "what to expect on rotation/exam." Everything else (great SRS, clean content, offline PWA) is table stakes. See [[AI-Personalization-Engine]].

## The four locked decisions (the frame)
1. **Audience:** Queen's-first, others welcome — never hardcode Queen's into the engine. [[Personas]]
2. **Content:** Hybrid — original core (public) + private import. [[Content-Strategy]] · [[Licensing-and-Copyright]]
3. **Personalization:** Full adaptive system driven by a per-answer performance log. [[AI-Personalization-Engine]]
4. **Ambition:** A real, launchable product — not a personal script. [[Roadmap]]

## The test for any decision
Does it make a real clerk open the app *every day*, trust it to say *what to study now and why*, and feel *ready* on exam day? If not, it's off-mission.

## Where we are right now
Phases 0–1 shipped (study core, accounts/sync). Phase 3 (date/schedule awareness) core shipped. **Next frontier: Phase 4 — the attempt log** (per-answer telemetry), the substrate the AI tutor needs. See [[Roadmap]] · [[Backlog]].
